## Project Overview

This project focuses on analyzing smartphone purchasing behavior using data analytics techniques and Power BI visualization.

The goal was to explore customer preferences, identify purchasing patterns, and transform raw data into meaningful insights through interactive dashboards.

---

## Business Questions

The analysis focused on questions such as:

- What factors influence smartphone purchasing decisions?
- Which smartphone features are most important to customers?
- What patterns can be identified from customer data?
- How can visualization help support decision-making?

---

## Tools & Technologies Used

- **Power BI** — Interactive dashboards and data visualization
- **Excel** — Data preparation and exploration
- **Data Analysis** — Identifying trends and patterns
- **Data Visualization** — Presenting insights clearly

---

## Data Analysis Process

The project followed a structured analytics workflow:

### 1. Data Preparation

The dataset was reviewed, cleaned, and prepared for analysis.

### 2. Data Exploration

Different variables were analyzed to understand customer behavior and purchasing trends.

### 3. Dashboard Development

Power BI was used to create interactive visuals that highlight important patterns and insights.

---

## Key Insights

The dashboard helped reveal:

- Customer purchasing preferences
- Important smartphone features influencing decisions
- Trends within smartphone selections
- Opportunities for better business understanding

---

## Conclusion

This project demonstrates how data analytics and visualization can transform raw information into actionable insights.

By using Power BI, meaningful patterns can be discovered and presented in a way that supports data-driven decision-making.
